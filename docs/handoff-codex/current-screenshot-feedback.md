# 用户反馈：当前效果 vs 目标效果

## 用户截图反馈（2026-04-23）

用户看到当前效果后不满意，原话："你确定这是最终效果吗"

### 当前效果问题分析

1. **背景太暗太平** — 渐变光晕虽然定义了但视觉上几乎看不出来
   - 需要：更亮的蓝色天际光（opacity 0.4-0.5），更明显的紫色底部光
   - 需要：底部山峦轮廓渐变更加分明
   - 需要：星点效果更可见

2. **面板和背景色差不明显** — 侧边栏、顶栏虽然改了透明度但看起来和背景差不多
   - 需要：背景渐变足够亮，面板玻璃效果才能体现
   - 需要：内发光效果（inset box-shadow）增强面板浮动感

3. **完全缺少渐变边框** — `--border-glow` token 定义了但没有一个组件使用
   - 需要：侧边栏右边框、顶栏底部边框、输入框边框、卡片边框都要渐变

4. **缺少渐变文字效果** — 只有 Logo 有，其他标题都是纯色

## 目标效果（G.TAKE 参考图）

G.TAKE 参考图的关键视觉特征（按重要性排序）：

1. **超强大气渐变背景** — 不是微弱的光晕，而是很明显的蓝紫渐变，像山间星空
2. **明显的面板玻璃效果** — 面板半透明且能清晰看到背景渐变透过来
3. **渐变边框** — 面板边缘有从左上到右下的蓝色渐变光边
4. **渐变文字** — 标题用白→蓝→天蓝渐变
5. **层次深度感** — 通过不同透明度和模糊度创造前后层次
